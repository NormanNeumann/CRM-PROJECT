# CRM PROJECT

将项目压缩包完整解压，用桌面浏览器打开 `index.html`。项目通过普通脚本加载，不需要安装依赖或连接网络。

## 演示流程

1. 在线索页点击「添加新线索」，输入姓名和 11 位数字手机号，选择高、中或低优先级。保存成功后，列表会清除旧筛选，并在首行高亮新记录。
2. 点击「高优先待转化」查看未转化的高优先线索。点击「转为客户」填写跟进人并确认。相同手机号已有客户时，确认后会关联该客户。
3. 回到线索页，点击「已转为客户」。优先级栏显示「已转化」。行内点击「客户管理」可定位到唯一关联的客户。
4. 从客户行点击「建订单」，或到订单页点击「添加订单」并选择客户。填写商品名保存后，可看到订单编号和客户信息。
5. 点击「线索总数」清除所有线索筛选。每张统计卡的数字按全部线索计算。

## 目录

- `index.html` 页面入口
- `assets/styles.css` 布局、品牌、交互与响应式样式
- `js/data.js` 示例记录、数据存储与编号规则
- `js/app.js` 列表、表单校验、筛选与业务操作

演示数据保存在当前浏览器。已转化状态由关联客户编号决定，原始优先级保留，供新客户继承。可访问同一来源的旧版演示数据时，项目会自动读取。浏览器可能按本地文件路径隔离存储；换目录或换浏览器可能会进入新的演示工作区。
